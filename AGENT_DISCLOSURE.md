# Agent Disclosure

Coding-agent assistance was used to develop this project.

Representative trajectories are included in:

- `trajectories/trace_analyst.jsonl`
- `trajectories/verification_planner.jsonl`
- `trajectories/execution.jsonl`
- `trajectories/auditor.jsonl`

Each shows the action, tool/evidence interaction, feedback or handoff, and resulting decision.

The benchmark itself does not require an external model API. This makes the measured comparison reproducible without credentials.
